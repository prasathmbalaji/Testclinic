# Mind Care Clinic static website demo

## Run locally
Open `index.html` in a browser, or run a local static server from this directory:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Included pages
- Home
- About Doctor
- Services
- Mental Health Resources
- Patient Information
- Reviews
- Contact / appointment enquiry
- Privacy Notice

## Important before publishing
This is a static demonstration only. The appointment form does not submit or store data.
Confirm all clinic details, doctor credentials, registration, services, address, fee, timings,
phone numbers, email and Google Business Profile link directly with the clinic.
Obtain permission for the clinic logo, doctor photograph and testimonials.
Review the privacy notice and medical content before production.
Replace the Google Maps search link with a confirmed clinic pin or approved embed.
Connect a secure backend and notification workflow only after clinic approval.
